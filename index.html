Multrif.

Multrif adalah media belajar interaktif untuk memahami dasar dasar pemrograman web. Baca materinya, coba langsung kodenya, lalu uji pemahamanmu lewat latihan dan evaluasi.

Apa yang Kamu Bisa Pelajari?

Tiga fondasi pemrograman web yang akan kamu kuasai, lengkap dengan simulasi kode langsung.

HTML

Menyusun struktur dan isi halaman web, mulai dari tag, elemen, heading, sampai form.

CSS

Mengatur tampilan halaman, mulai dari warna dan font sampai tata letak yang responsif.

JavaScript

Menambahkan interaksi pada halaman, mulai dari event klik sampai memanipulasi elemen lewat DOM.
