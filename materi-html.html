1

Pengertian & Fungsi HTML

Teks Penjelasan

HTML (HyperText Markup Language) adalah bahasa markup yang dipakai untuk menandai bagian bagian dokumen sehingga browser tahu cara menampilkannya. Kata “HyperText” merujuk pada kemampuan HTML menghubungkan satu dokumen ke dokumen lain melalui tautan.

Fungsi utama HTML antara lain menyusun struktur dokumen, menandai jenis konten seperti judul, paragraf, dan gambar, menjadi wadah bagi elemen yang nanti diberi gaya oleh CSS dan diberi perilaku oleh JavaScript, serta menyediakan aksesibilitas dasar bagi pembaca layar.

Gambar / Ilustrasi

Video

Contoh Kode

<h1>Judul Berita</h1>
<p>Ini paragraf isi berita.</p>
2

Struktur Dasar Dokumen HTML

Teks Penjelasan

Setiap dokumen HTML memiliki kerangka baku yang terdiri atas deklarasi tipe dokumen, elemen akar <html>, bagian kepala <head> yang berisi metadata, dan bagian tubuh <body> yang berisi konten yang ditampilkan kepada pengguna.

Bagian <head> tidak tampil langsung di halaman, tetapi berisi informasi penting seperti judul tab browser (<title>) dan pengaturan karakter (<meta charset>). Bagian <body> berisi seluruh konten yang terlihat, mulai dari heading, paragraf, gambar, sampai form.

Gambar / Ilustrasi

Video

Contoh Kode

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Halaman Pertama Saya</title>
</head>
<body>
  <h1>Selamat Datang</h1>
  <p>Ini adalah paragraf pertama saya.</p>
</body>
</html>
3

Tag, Elemen & Atribut

Teks Penjelasan

Tag adalah penanda yang ditulis di antara kurung sudut, digunakan untuk menandai awal dan akhir suatu bagian konten. Sebagian besar tag berpasangan, yaitu tag pembuka seperti <p> dan tag penutup seperti </p>. Ada juga tag kosong yang berdiri sendiri, misalnya <img> dan <br>.

Elemen adalah gabungan dari tag pembuka, isi konten, dan tag penutup secara keseluruhan. Jadi <p>Halo</p> disebut satu elemen paragraf, sedangkan <p> saja hanyalah tag. Elemen dapat berisi elemen lain di dalamnya, disebut elemen bersarang.

Atribut adalah informasi tambahan yang ditulis di dalam tag pembuka untuk mengatur atau memberi data ekstra pada elemen tersebut. Atribut ditulis dengan format nama sama dengan nilai, dan satu elemen dapat memiliki lebih dari satu atribut, contohnya href dan target pada tag <a>.

Gambar / Ilustrasi

Video

Contoh Kode

<a href="https://unm.ac.id" target="_blank" title="Kunjungi situs UNM">Situs UNM</a>
<p>Ini paragraf dengan <strong>kata penting</strong> di dalamnya.</p>
4

Heading

Teks Penjelasan

Heading digunakan untuk menandai judul dan sub judul, mulai dari <h1> yang paling penting sampai <h6> yang paling kecil. Heading bukan sekadar untuk memperbesar teks, tetapi menunjukkan hierarki informasi pada halaman.

Gambar / Ilustrasi

Video

Contoh Kode

<h1>Judul Utama Artikel</h1>
<h2>Sub Judul Bagian Pertama</h2>
<h3>Sub sub Judul</h3>
5

Paragraf

Teks Penjelasan

Tag <p> digunakan untuk menandai satu blok teks sebagai paragraf. Browser otomatis memberi jarak di atas dan bawah setiap paragraf, sehingga teks tidak menyatu menjadi satu blok panjang.

Video

Contoh Kode

<p>HTML digunakan untuk menyusun struktur halaman web.</p>
<p>CSS digunakan untuk mengatur tampilannya.</p>
6

Link (Tautan)

Teks Penjelasan

Tag <a> digunakan untuk membuat tautan menuju halaman lain, bagian lain dalam halaman yang sama, atau alamat email. Atribut href berisi tujuan tautan, dan target sama dengan _blank membuka tautan di tab baru.

Video

Contoh Kode

<a href="https://www.unm.ac.id">Kunjungi UNM</a>
<a href="#materi-css">Loncat ke bagian CSS</a>
<a href="mailto:contoh@email.com">Kirim Email</a>
7

Gambar (Image)

Teks Penjelasan

Tag <img> menampilkan gambar pada halaman. Tag ini termasuk void element yang tidak memiliki penutup, wajib memiliki atribut src sebagai sumber gambar, dan disarankan memiliki atribut alt sebagai teks alternatif untuk aksesibilitas.

Video

Contoh Kode

<img src="pemandangan.jpg" alt="Pemandangan gunung saat matahari terbit" width="400">
8

List (Daftar)

Teks Penjelasan

HTML menyediakan dua jenis daftar utama, yaitu daftar tak berurutan <ul> dengan bullet dan daftar berurutan <ol> dengan angka. Setiap item daftar ditandai dengan <li>.

Gambar / Ilustrasi

Video

Contoh Kode

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Pahami struktur HTML</li>
  <li>Pelajari tampilan dengan CSS</li>
</ol>
9

Tabel (Table)

Teks Penjelasan

Tabel digunakan untuk menampilkan data dalam bentuk baris dan kolom, memakai <table> sebagai pembungkus, <tr> untuk baris, <th> untuk sel judul kolom, dan <td> untuk sel data biasa.

Video

Contoh Kode

<table border="1">
  <tr>
    <th>Materi</th>
    <th>Fokus Utama</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>Tag, Elemen, Form</td>
  </tr>
</table>
10

Form

Teks Penjelasan

Form dibangun dengan tag <form> sebagai pembungkus, berisi elemen input seperti <input>, <textarea>, <select>, dan <button>. Setiap input umumnya memiliki atribut type yang menentukan jenis data yang diminta, serta atribut name sebagai nama data saat dikirim.

Atribut required membuat sebuah input wajib diisi sebelum form dapat dikirim, dan tag <label for="..."> dihubungkan dengan id pada input agar label dapat diklik untuk memindahkan fokus ke input terkait.

Gambar / Ilustrasi

Video

Contoh Kode

<form>
  <label for="nama">Nama Lengkap:</label>
  <input type="text" id="nama" name="nama" placeholder="Masukkan nama Anda">

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Kirim</button>
</form>
